# DREESHFILMEDIT | Editing workspace

This repository is a simple, no-build website. The live page is `index.html`.

## Where things go
- `assets/images/hero/`: homepage hero and banner photography
- `assets/images/portfolio/`: client work, sports, automotive, and documentary stills
- `assets/images/nature/`: nature and landscape photography
- `assets/images/branding/`: logos, wordmarks, and brand graphics
- `assets/images/placeholders/`: temporary images used while designing
- `assets/video/`: video files and lightweight preview clips
- `assets/fonts/`: licensed font files you are allowed to use on the site
- `assets/icons/`: custom icons and small graphic assets
- `content/`: editable website copy and service information
- `prompts/`: prompts and instructions for AI-assisted editing
- `components/`: planning notes for reusable website sections

## Safest editing workflow
1. Open `index.html` to edit the actual website.
2. Use the files in `content/` as the approved source for wording.
3. Add photos to the matching folder in `assets/images/`.
4. Ask GitHub Copilot or another coding AI to make one focused change at a time.
5. Preview the site before publishing. A commit to the production branch may trigger a live deployment.

## Important
Folders are created by the starter files inside them. Do not delete `index.html`. Do not replace the whole page when you only need a small edit. Keep the uploaded `dree.jpg` in the repository root for now; move it only after deciding where it belongs.

## Website image path examples
- `assets/images/hero/homepage-hero.jpg`
- `assets/images/portfolio/football-highlight-01.jpg`
- `assets/images/nature/forest-detail-01.jpg`

Use exact capitalization and file extensions in image paths.
